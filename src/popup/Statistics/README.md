# Statistics

Stat tiles (sites checked, threats blocked, warnings, downloads stopped), a 7-day
bar chart of sites checked (hover/focus a bar for the day's threat count), verdict
counts and engine counters (VirusTotal requests, cache hits, links/documents scanned,
bypasses). Bar heights are set through the CSSOM because the extension CSP forbids
inline `style` attributes. Data: `statsStore` (live).
