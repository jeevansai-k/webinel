Privacy

Protect first. Respect privacy always.

  • Webinel has no servers, no accounts and no sign-in. Everything it stores stays in your browser on this device.
  • The only outside service is VirusTotal, and only when you add your own API key. There is no telemetry and no analytics. Webinel sends VirusTotal the domain of sites you open and — only when you ask — a full address or a document's SHA-256 fingerprint.
  • Links are submitted to VirusTotal for new analysis only when you run Scan Now on a link it has not seen before, or Advanced Analysis. Submitted links become visible to the VirusTotal community.
  • Files are uploaded only if you press Upload to VirusTotal for that file. Uploaded files are shared with VirusTotal and its security partners — do not upload confidential documents.
  • Your API key is encrypted, stored locally, never synchronised, never shown again after saving, and sent only to VirusTotal to authenticate.
  • Webinel never stores email bodies, raw clipboard contents or your browsing history. Cached results are keyed by one-way hashes and contain no addresses or file names; the timeline records security events by domain or file name only.
  • The Email Link Scanner and Clipboard Scanner run only when you turn them on and press scan. They read links — never message text.
  • Removing the extension deletes all of its data.
